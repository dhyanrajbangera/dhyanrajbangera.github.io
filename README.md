# Dhyanraj Bangera — Portfolio

A responsive, single-page personal portfolio built with plain HTML and CSS.

## Publish with GitHub Pages

1. Create a **public** repository named `dhyanrajbangera.github.io`.
2. Upload `index.html` to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment, visit https://dhyanrajbangera.github.io.

GitHub Pages may take several minutes to publish the first time.

## Personalize before publishing

- Add a professional email address or LinkedIn link if you want visitors to contact you directly.
- Replace project summaries with final details and link each project card to its repository once the repository URLs are confirmed.
- Add project photographs in a folder such as `assets/` and reference them from `index.html`.

Only publish information and contact details you are comfortable making public.
